# LinkedIn project description

**Project title:** SEC-002 — Home Network Asset Investigation

Investigated two unfamiliar home-network entries using Windows ping and ARP, an EXOS router inventory, MAC manufacturer lookups, and household context. Correlated the observations to identify likely Chamberlain/myQ garage equipment and a Samsung Smart TV, while documenting the limits of vendor lookups and ping results. Created a privacy-safe case study that separates observations from conclusions and omits private network identifiers.

**Skills:** Network troubleshooting · Asset inventory · Evidence correlation · Technical documentation
